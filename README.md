# undangan_digital

Platform **Undangan Pernikahan Digital Multi-Client** dengan desain *Couture Editorial & Fine Letterpress Stationery*, dilengkapi Dashboard CMS Super Admin, Multi-Client Switcher, serta Theme & Appearance Customizer per klien.

## Fitur Utama
- **Multi-Client Management (`/admin/clients`)**: Kelola banyak undangan klien dalam satu aplikasi dengan URL unik (`/:slug`), fitur *Quick Switcher*, dan kloning data cepat.
- **Custom Theme & Appearance Engine (`/admin/appearance`)**: Kustomisasi preset palet warna, warna bebas (*color picker*), pasangan tipografi Google Fonts, gaya ornamen (*Adat Minang*, *Floral*, *Minimalist*), bentuk bingkai potret (*Arch*, *Oval*, *Rounded*), visibilitas section, dan teks sapaan.
- **Couture Editorial UI**: Tampilan sampul, profil mempelai, hitung mundur horologi, jadwal acara, kisah cinta, galeri pameran, amplop digital (*Tanda Kasih*), dan buku tamu RSVP real-time berbasis PostgreSQL.
